# 公众号爆文写作指南

> 本流水线的核心方法论。AI 写初稿必须遵循本指南；润色者用它对照修改。
> 适用范围：**所有账号共用本指南**——文序云启（company）、高坡（gaopo）均执行同一套纪律。
> 用户明确偏好：**默认用 C 悬念倒叙或 A 事故切入**。禁流水账——「一、二、三、四」顺序推进的操作手册式文章没人读。

## 0. 选题判断

爆文选题四象限（命中至少一个才有爆的潜质）：

| 类型 | 内核 | 标题味道 |
|---|---|---|
| 事故复盘 | 真实踩坑 + 损失数字 | 「一次 XX 事故，损失了 XX」 |
| 反共识 | 大家都做错了 | 「你一直在用的 XX，其实是错的」 |
| 悬念揭秘 | 藏得深的真凶 | 「查了 3 天，凶手竟然是它」 |
| 避坑指南 | 可复用的 checklist | 「上线前必查的 5 个点」 |

技术正确 ≠ 有人读。**把「讲全流程」换成「讲一个带代价的故事」。**

## 1. 标题公式（≤32 字，微信硬限制）

三要素挑两个组合：数字（损失/收益/比例）、悬念缺口（不说破）、反常识断言。

- 数字+损失：「一个弹窗，能让 40% 的用户永久关闭你的推送」
- 悬念+复盘：「72 小时推送事故：凶手藏在第 3 天的日志里」
- 反共识：「你的 APNs 代码没 bug，但它每天都在掉 30% 推送」
- 避免：完整句号结尾、双问号、「浅谈/详解/一文读懂」（AI 味标题）

## 2. 三种叙事骨架

### A 事故切入
钩子（事故现场）→ 排查过程（两次误判）→ 真因反转 → 解法（技术点出场）→ 复盘清单

### B 反共识
共识陈述（大家都这么做）→ 证据否定（数据/事故）→ 为什么一直没发现 → 正确做法 → 迁移成本评估

### C 悬念倒叙（默认首选）
结果先曝光（最糟的时刻）→ 以为的原因全错 → 真凶浮出（反转）→ 解法代码 → 三个决策错误复盘

**每节的转折设计**：铺垫（正常）→ 异常（细节不对劲）→ 反转（真相）→ 解法（技术点作为解法出现，不要提前上课）。

## 3. 密度要求

- 每 ≤300 字一个记忆点：金句 / 反转 / 具体数字 / 反常识断言
- 导语 ≤60 字，一句话把画面或代价摔在读者脸上
- 代码块只放「解法」代码，单块 ≤25 行；讲完代码必须回到故事
- 全文 1200-2200 中文字最佳；>2500 字完读率崩
- 小节 3-6 个，每节标题本身要有信息量（「以为的原因，全错」优于「排查过程」）

## 4. 金句写法

- ❌ 技术描述平铺：「registerForRemoteNotifications() 必须在拿到授权后调用」
- ✅ 代价具象化：「一个弹窗，能让 40% 的用户永久关闭你的推送」
- ✅ 重新定义：「200 是接口成功，不是用户看到」「410 是讣告，不是错误码」
- 公式：把抽象指标换算成用户可感知的损失

## 5. 发布前自检（check_article.py 自动查一半）

1. 标题 ≤32 字、无 `【】` 占位符残留
2. 无 `【` `TODO` 残留 anywhere
3. 中文字数 800-2500
4. 小节 3-6 个
5. 导语 ≤60 字
6. 每个代码块 ≤25 行
7. 结尾有复盘清单（3 条决策错误或行动清单）
8. 海报和 END 标记由 wxpub 服务端自动生成，**不要写进正文**

## 6. 润色原则

初稿出来后只做三类修改：砍（删铺垫和重复）、换（把技术描述换成代价化表达）、核（数字与代码真实性）。结构不动——结构错了不如重写。

## 7. 事实纪律（用户明确要求：实事求是，反营销爽文）

爽文感往往来自素材而非文笔。选素材时执行以下纪律：

1. **预测、估算、事实三类分开写。** 「Forrester 预测 2030 年 49%」必须带「预测」字样；「消失 200 万岗位」这类二手估算禁用，除非原始口径可核对。
2. **单一信源不用，利益相关方降权。** 政绩通稿（政府网站、产业园宣传）只能作为「存在性证据」，不能作为规模/效果证据；厂商研究（如 CSAT 提升 25%）默认是营销素材。
3. **报喜也报忧。** 引用「带动 X 万人次就业」时，顺手算人均产值/工资水平/单价跌幅，给读者完整量级。
4. **反例优先。** 每个论点先找反例数据（如写数据标注红利，必查自动化替代率、净利率、单价跌幅），反例找不到才允许立论。
5. **金句可以为观点服务，不能为数字服务。** 数字必须原样引用并标注来源属性（文件号/媒体/论文/业内估算）。

## 8. 原创纪律（2026-10-04 用户定版，所有平台通用）

我们是创新，不能搬运。百家号判例：《阳泉为什么叫阳泉》（自写稿）因与站内现有内容高度相似被限仅主页可见——**自己写的也会撞车**，所以：

1. **只写原创。** 不复制、不拼接、不洗稿、不复述他人文章；不把别人文章的讲述结构改几个词就用。
2. **选题先查重。** 动笔前在目标平台站内 + 搜索引擎搜选题关键词；同角度文章已大量存在（通版角度）就不能当主轴，必须换增量角度：新考古结论、新史料、反例、实地细节、人物。
3. **事实可重合，讲法必须自己造。** 事实无版权，但切入角度、结构、类比、金句必须是自己的。
4. **被判「高度相似」的处置。** 实质性改写后重发，或凭原创依据（信源链、写作记录）申诉；不硬扛限流。
5. **术语约定。** 「搬运」只许指自己原创稿在自家账号编辑器间的转写同步，绝不指他人内容。
